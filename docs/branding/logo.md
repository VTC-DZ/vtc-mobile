# Rapidoo logo

The approved design is the first white road-shaped R on a black background.
The transparent preview was given an opaque black background using the built-in
imagegen tool before exporting the platform icons.

The master asset is `assets/images/logo/logo.png` (1254 × 1254, opaque PNG).
Android, iOS, macOS, web, and Windows icons are resized exports of this master.
Web maskable icons include extra black padding to protect the mark when cropped.
The Windows ICO contains 16, 24, 32, 48, 64, 128, and 256 pixel versions.

## Final imagegen prompt

```text
Use case: background-extraction.
Asset type: approved Rapidoo mobile launcher icon, production export.
Input image: edit target, the user's approved FIRST white R road monogram, previously displayed on black.
Primary request: preserve the exact approved white R silhouette, curved road-shaped cutout, proportions, position and generous padding. Change ONLY the transparent background to solid opaque pure black #000000. All transparent pixels and the road cutout must show the same solid black. White logo remains white. Preserve the original design faithfully; no redesign, no green, no extra elements.
The entire image must be a fully opaque square image, every pixel opaque, with the white monogram centered on black. The black is required artwork, DO NOT remove it or produce transparency. No shadows, gradients, presentation frames, rounded outer corners, wordmarks or labels.
```
